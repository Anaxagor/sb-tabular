## Additional defects corrected

| Area | Failure found | Correction |
|---|---|---|
| Saved datasets and splits | Loading trusted stored hashes without checking actual values and memberships; preparing splits could retain old data when row membership was unchanged. | Recompute the data fingerprint, verify schema order and source row IDs, partition/count/hash invariants, and actual declared KFold membership. Refuse changed values even when the split membership matches. |
| CV provenance | Existing folds could be reused after implementation changes or after generator artifacts disappeared. Partial runs replaced parts of the seed ledger. | Check data, schema, split, config, implementation, adapter/checkpoint format and library compatibility; hash generator artifacts; validate before reuse; merge fold statuses and seeds. |
| Tuning resume | A missing sampler file silently restarted its RNG; it was only saved after training. A completed-study resume lost its seed ledger, and a failed best-checkpoint reload could leave a stale selected config. | Persist the sampler after suggestions and trial completion, require its state for populated studies, retain seeds, and revoke a selection that is no longer final. Include library versions in compatibility. |
| Failed/partial evaluations | A failed fold's flat record was appended after the JSON had been saved; incomplete evaluation could be reported as complete five-fold output. | Persist failures before aggregation, count observed output folds, and preserve missing/failed fold exclusions. |
| Rank comparisons | Multiple runs for one dataset/fold/model were arbitrarily collapsed; a requested but absent model disappeared from the comparison. | Reject ambiguous runs and incompatible metric/data/split definitions, retain requested model coverage, and decline comparisons without shared eligible cells. |
| Categorical values | Fractional state IDs were truncated into valid categories; casting nonfinite values could conceal invalid output or fail during serialization. | Validate finite integral IDs before conversion in native representations, baseline decoders, preprocessing and native solver inputs. Preserve invalid synthetic values in Parquet for validity reporting. |
| Fit state and timing | Exceptions lost stage timings, retained encoded training rows, and could leave a previously fitted adapter/preprocessor usable after a failed refit. | Measure failed operations in `finally`, release adapter training rows, invalidate state before refitting, and copy failure timings into experiment records. |
| Utility evaluation | Failures while freezing parameters or fitting the real-data reference escaped the utility failure handler and discarded otherwise valid fidelity results. Undefined utility scores and utility-gap directions/units were flattened incorrectly. | Retain fidelity and timing on utility initialization/fit failures, propagate score statuses, and give gaps their proper direction/unit metadata. |
| Conditional metrics/configuration | Partial conditional coverage was marked `ok` in nested means/blocks and lost in flat results; unknown metric settings were silently ignored. | Carry incomplete coverage through nested and flat records, count affected folds, and strictly validate metric settings/version/KL direction. |
| Neural reproducibility | IPF-DSB CT/DT dropout and MixedSBM training depended on the caller's Torch RNG. MixedSBM sampling constructed temporary networks using that RNG. | Seed local training RNG contexts and isolate temporary sampling initialization. Tests check identical fits under different caller RNG states and preservation of caller state. |
| Solver inputs/checkpoints | Zero training budgets could produce an apparently fitted CSBM/MixedSBM; CSBM reload reset update counts. Nonfinite grid/reference parameters were accepted. | Reject invalid budgets/parameters and fractional native category inputs, and restore training update counts from saved stage history. |
| Uniform categorical reference | The nominally linear-storage kernel retained a dense identity matrix of size support². | Construct requested transition rows directly; allocate a dense identity only for the explicit diagnostic `dense()` method. Existing independent kernel/bridge oracles still pass. |

## Compatibility and remaining limits

Corrected evaluation output uses `sbtab.evalstage/2` and the directory suffix `-eval2`; the metric
formula version remains `sbtab.metrics/1`. Earlier evaluation directories are retained. CV reuse
now requires the recorded compatibility and artifact hashes. Older CV runs lacking those fields,
or runs from a different implementation, must not be extended in place; start a new run. Existing
saved outputs can still be evaluated without loading generator checkpoints. Tune resume now also
requires matching recorded library versions and its persisted sampler file.

The following claims remain unsupported or requirements remain unmet:

- **Intermediate training resume:** checkpoints are inference-complete. Optimizer/scheduler/RNG/cache
  state for mid-fit restart and cumulative timing across such restarts are not implemented. An
  interrupted trial is reconciled as failed; the study can continue with its remaining allocated
  budget. This is an outstanding PDF §7 requirement, not equivalent to training resume.
- **Optional implementations:** eight skipped tests require SDV or TabPFGen/TabPFN; one requires
  geotorch for full-covariance LightSB. Their real dependency paths were not validated here.
- **GPU and production quality:** GPU execution/nondeterminism and the full 100-trial benchmark were
  not exercised. Smoke fits establish lifecycle behavior, not statistical quality or convergence.
- **Prior documented limitations:** process-level peak-memory measurement, short legacy default IPF
  horizons, upstream baseline internals, unavailable algorithms, and the frozen legacy pipeline
  retain the qualifications in the original report. The active pipeline does not use the legacy
  metric definitions or data modules.
